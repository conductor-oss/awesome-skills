You synthesize the repositioning discovery phase into a single discovery output JSON. Inputs: current-positioning audit, web/market research, competitor scan, and the user's optional ICP hypothesis. Your output feeds every downstream phase — be honest about ground truth.

## Variables

- product: ${product}
- icp_hypothesis: ${icp_hypothesis}
- current_positioning: ${current_positioning}
- web: ${web}
- competitors: ${competitors}

## INPUT VALIDATION

- ${product} must have name and description.
- The three discovery inputs (current_positioning, web, competitors) may be null if upstream tasks failed; in that case flag in gaps and lower ground_truth_score accordingly.
- ${icp_hypothesis} is optional.

If product is missing, output: {"_error":"missing_product"} and stop.

## What to produce

1. **market_summary**: 4–8 sentences synthesizing:
   - What's happening in this market now
   - What's changed since the product's original positioning
   - Why current positioning is breaking (cite current_positioning.evidence_of_misfit)
   - What opening exists (cite web.adjacent_categories_to_consider or competitors.positioning_whitespace)
   Be specific. Cite sources inline when possible (e.g., "per current_positioning audit, the homepage still leads with 'workflow orchestration' while docs reference 'agent runtime' — this inconsistency surfaces in competitor comparison pages").

2. **category**:
   - name: the category we believe is most advantageous (pull from web or competitor analysis)
   - alternatives: the named alternatives buyers compare against — include DIY, status quo, AND specific named vendors

3. **competitors**: Pull from competitors.competitors. Preserve fields verbatim (name, positioning, strengths, gaps, sources).

4. **customer_signals**:
   - from_corpus: signals extracted from user-supplied materials (current_positioning.lost_deal_patterns, current_positioning.current_positioning_claims). Each: quote, source, theme. EMPTY if no corpus signals.
   - from_web: signals from web research (web.public_perception_signals). Each: quote, source, theme. EMPTY if no web signals.

5. **ground_truth_score**: 0.0 to 1.0. Be honest:
   - 0.8+: rich corpus (multiple files with real customer quotes) + strong web signals + verified competitor data
   - 0.5–0.7: some corpus content + some web signals, no win/loss data
   - 0.3–0.4: thin corpus, mostly training-knowledge research
   - <0.3: essentially no real data, just inferred-from-product-name
   Inflated scores poison every downstream step.

6. **gaps**: What you'd want for stronger discovery (e.g., "no win/loss interviews supplied", "AgentSpan repo returned empty README at fetch time", "competitor X's pricing page was not fetched").

## Output schema

Return STRICT JSON only.

02The shape

Skill on the front. Workflow underneath.

A skill alone is a prompt — it lives in your terminal until you close it. Backed by a Conductor workflow, the same skill becomes something else entirely: durable, parallel, and auditable.

A The skill

Conversational layer

Markdown plus YAML that your coding agent loads. Handles intake, status, mid-run inspection. Stateless, portable across Claude Code, Codex CLI, Gemini CLI, OpenCode.

B The workflow

Durable engine

A Conductor process running on a server. Parallel LLM tasks, retries, persistent state, audit trail. Survives your laptop closing, the session ending, you walking away for the weekend.

A+B The trade

30–60 min of real work

Long-running agent runs you can review opportunistically, pause across days, resume in any new session. Strategy, research, multi-step orchestration — the kind of work no single prompt could finish.

04What you get

Things a single prompt can't do.

i

Durable state

Workflow state lives on the server. Close your laptop. Switch agents. Restart your machine. Resume the next morning.

ii

Real parallelism

Six LLM tasks fork at once and a judge composes the winner. Not chained prompts — actual parallel branches with structured outputs.

iii

Refinement loops

Draft → adversarial probe → revised draft, repeated until a quality gate passes. Trivial in a workflow, hard in a single prompt.

iv

Audit trail

Every line of output traces back through the decisions log to a panel critique or strategic fork. No "the model just said so."

v

Mid-run inspection

Ask "show me the ICP" while phase four is still running. The skill surfaces whatever the synthesis loop has produced so far.

vi

Concurrent runs

Multiple workflows in flight at once. Disambiguate by product name. The skill keeps them straight.

05Start

One command. Every agent on your machine.

The installer auto-detects which coding agents you have and symlinks the skill into each. Re-runnable. Safe to retry. No global install required.

$npx @conductor-skills/gtm --agent codex — or pick one
$npx @conductor-skills/gtm --bootstrap — also set up Conductor + register workflows

06For contributors

The shape every skill in this repo follows.

The principle: the skill is conversational and stateless; the workflow is durable and parallel. Anything that must survive a session belongs in the workflow. Anything the user types belongs in the skill. 

<skill-name>/
├── SKILL.md                          # conversational orchestrator
├── bin/                              # npx installer
├── docs/design/architecture.md       # engineering reference
├── references/
│   ├── workflow-definitions/         # Conductor workflows (JSON)
│   ├── personas/                     # persona contracts
│   ├── prompt-templates/             # per-phase prompts
│   ├── output-templates/             # Mustache markdown
│   └── platform-tools.md             # tool-name mapping
├── scripts/
│   ├── install_check.sh              # interactive deps + server
│   ├── register_workflows.sh         # idempotent upsert
│   └── build_workflow.py             # canonical patcher
├── evals/                            # static + bundle + e2e
└── package.json                      # @conductor-skills/<name>

Conversational, not configurational.

The skill talks. It asks for what it needs in plain English, one question at a time. No flags. No JSON. No workflow IDs.

Durable state belongs in the workflow.

If it has to survive a session, it lives in Conductor. The skill remembers nothing between turns; it queries state on demand and translates it back.

Personas as operating systems.

When a skill uses personas, they're structured field contracts — principles, evaluation questions, anti-patterns — applied mechanically by the workflow, not vibes.

Forks beat consensus.

When multiple model passes disagree on a high-stakes call, the skill preserves the fork with tradeoffs spelled out. The operator decides; the model never auto-resolves.

Every artifact is auditable.

Every line of final output traces back to a recorded critique, judge decision, or strategic fork. Strategy you can defend in a review.
